# QRVerse

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22978801.svg)](https://doi.org/10.5281/zenodo.22978801)

A cross-platform smart QR platform built with Expo SDK 57 and React Native.

## Features

- Smart QR Code Generator
- QR Scanner
- File Upload
- Link Vault
- Supabase Authentication
- AI OCR & Translation
- Offline File Bridge (development)

## Tech Stack

- Expo SDK 57
- React Native
- TypeScript
- Supabase
- GitHub
- Vercel

## Installation

```bash
npm install
npx expo start
```

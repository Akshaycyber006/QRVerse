# QRVerse

A cross-platform smart QR platform built with Expo SDK 57 and React Native.

## Features

- Smart QR Code Generator
- QR Scanner
- File Upload
- Link Vault
- Supabase Authentication
- AI OCR & Translation
- Offline File Bridge (development)

## Tech Stack

- Expo SDK 57
- React Native
- TypeScript
- Supabase
- GitHub
- Vercel

## Installation

```bash
npm install
npx expo start
